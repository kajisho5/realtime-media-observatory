# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately, not through a public GitHub issue:

1. Go to this repository's **Security** tab.
2. Click **Advisories** → **Report a vulnerability**.

This opens a private report visible only to the maintainers, so the issue can be triaged and fixed before any public disclosure.

## Supported Versions

This project is pre-1.0 and does not currently maintain multiple supported release lines. Security fixes are applied to the latest release.
